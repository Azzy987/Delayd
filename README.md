# Delayd

Delayd is a behavior-changing iOS app that reframes spending as time delayed from personal dreams.

## Stack

- SwiftUI (iOS 17+)
- SwiftData
- RevenueCat (IAP)

## Project Structure

- `Delayd/` — main iOS app target
- `DelaydWidget/` — widget extension
- `DelaydTests/` — unit tests
- `DelaydUITests/` — UI tests

## Getting Started

1. Open `Delayd.xcodeproj` in Xcode.
2. Select the `Delayd` scheme.
3. Build and run on iOS 17+.
